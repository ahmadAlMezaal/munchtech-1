# Munchtech-1

The office snack machine. Pick your name, press **Consume**, and the receipt keeps track of who had what.

Most of its features are built by AI coding agents from Linear tickets, through [Noctra](https://github.com/onelastcommit/noctra). It's a live demo of turning a plain-English ticket into a reviewed pull request.

```bash
npm install
npm run dev
```

Data lives in your browser's `localStorage`, so everyone's machine starts from the same seed and keeps its own history.
